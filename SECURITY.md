# Sécurité / Security

## Signaler une faille

Ne l'ouvrez **pas** en ticket public. Utilisez l'onglet
**Security → Report a vulnerability** de ce dépôt (signalement privé GitHub),
ou écrivez à **hello@getimiel.com** avec « Sécurité » dans l'objet.

Dites ce que la faille permet, comment la reproduire et la version touchée.
Vous recevez une réponse sous 72 heures ; la correction est publiée dès
qu'elle est prête, et vous êtes crédité si vous le souhaitez.

**Compte comme faille** : lire ou modifier les mails, réglages ou fichiers
d'un autre compte, contourner la connexion, récupérer un mot de passe de boîte
ou une clé, ou faire exécuter une commande au serveur.

Seule la dernière version publiée sur `main` reçoit des correctifs.

## Reporting a vulnerability

Please do **not** open a public issue. Use **Security → Report a
vulnerability** on this repository, or email **hello@getimiel.com** with
"Security" in the subject. Describe the impact, how to reproduce it and the
affected version. You will get an answer within 72 hours. Only the latest
release on `main` receives fixes.
